# Artifacts

Generated or reference artifacts live here instead of the repository root.

| Directory | Role |
|---|---|
| [`diagnostics/`](diagnostics/README.md) | Diagnostic dashboard images from archived plot scripts. |
| [`experiments/`](experiments/README.md) | Sweep charts, phase diagrams, and small data files. |

Large structured simulation outputs stay in [`../runs/`](../runs) because that
directory is the experiment registry.
