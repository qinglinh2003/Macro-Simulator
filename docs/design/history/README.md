# Design History

This directory preserves the project's research trail: version arcs, falsified
hypotheses, diagnostics, and the changelog. It is valuable evidence, but it is
not the first-stop development guide.

- [`arcs/`](arcs/README.md) — long-form version arcs and findings.
- [`change-log.md`](change-log.md) — dense chronological changelog.

Use history when you need to answer "why was this mechanism built?", "what
failed before?", or "which diagnostic proved this artifact was real?"
